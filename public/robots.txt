# AI crawlers: sorted by what they do with the page, not by who runs them.
#
#   Training crawlers scrape text to feed a model. Nothing comes back — no
#   visit, no citation, no link — and the content ends up baked into weights
#   this site does not control. Blocked.
#
#   Assistant and AI-search crawlers fetch pages to answer a question someone
#   is asking right now, and cite the source. That is the same bargain as a
#   search engine: a mention and a link in exchange for a read. Allowed, so
#   that "who is Armel Gandour?" asked to ChatGPT, Claude or Perplexity finds
#   this site.
#
# Google is deliberately absent from the allowed group. Google-Extended is the
# only token it offers and it bundles Gemini *training* with grounding, so it
# stays blocked below. Google's own AI answers — AI Overviews and AI Mode —
# are not governed by it: they read the ordinary Search index that Googlebot
# builds above. No `nosnippet` or `max-snippet` is set anywhere, so the site
# remains quotable there. On Google, the plain referencing does the work.
#
# robots.txt is honoured voluntarily. The operators below publish their agent
# strings and do respect it; scrapers that do not are unaffected by any of
# this.
# ---------------------------------------------------------------------------
