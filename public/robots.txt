# AI crawlers: declined, both kinds.
#
# Two groups, kept apart because the trade-off is not the same:
#
#   Training crawlers scrape text to train a model. Nothing comes back — no
#   visit, no citation, no link. Blocking them costs nothing.
#
#   Assistant/search crawlers fetch pages to answer a question being asked
#   right now, and usually cite the source. Blocking them means "who is Armel
#   Gandour?" asked to ChatGPT, Claude or Perplexity returns nothing about
#   this site. That is a real loss of visibility, and it is deliberate here.
#   To reappear in those answers, delete that second group — leaving the
#   training group blocked.
#
# robots.txt is honoured voluntarily. The operators below publish their agent
# strings and do respect it; scrapers that do not are unaffected by any of
# this.
# ---------------------------------------------------------------------------
